# CS3237 Lab 1 — Getting Started with your Embedded System

ESP32 Arduino sketches for CS3237 Lab 1. Each folder corresponds to a task from the lab report.

| Task | Folder | Description |
|---|---|---|
| Task 1 | [Task1_Blink](Task1_Blink) | Blink program modified to blink with ever-increasing frequency until the LED stays permanently on. |
| Task 2 | [Task2_PWM_LED](Task2_PWM_LED) | PWM-driven LED that pulses brightness up and down continuously. |
| Task 3 | [Task3_Switch](Task3_Switch) | Switch toggle with software debouncing. |
| Task 4 | [Task4_Interrupt](Task4_Interrupt) | Interrupt-driven (ISR) button press counter with debouncing. |
| Task 5 | [Task5_DHT_LED](Task5_DHT_LED) | DHT11 temperature/humidity sensor that triggers an LED when a threshold is exceeded. |
| Task 6 | [Task6_Ultrasonic_LED](Task6_Ultrasonic_LED) | HC-SR04 ultrasonic distance sensor driving an LED that blinks faster as an object gets closer. |

See the lab report (submitted separately) for full write-ups of each task.
